# Bichario 🌿🐞

A cozy, living hand-drawn terrarium app — draw a *bicho*, name it, keep a Field Guide (*Bichodex*), paint living moss, and send critters to visit shared family jars.

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the full design rationale, Firebase data model, and lab roadmap.

## Installing the Android Lab APK

Grab the latest `bichario-lab-v0.x.x.apk` from the **GitHub Releases** tab, install it on your Android phone or tablet (finger or stylus), tinker with the labs, scribble your own menu ideas, and tap **Export Lab (.zip)** to share your config & sketches back!

## Local Development

```bash
npm install
npm run dev        # Run in browser (opens on LAN for phone testing too)
npm run build      # Typecheck + production bundle
npm run cap:sync   # Sync web build into Capacitor Android project
```
